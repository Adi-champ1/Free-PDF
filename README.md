Default files — the app pre-loads these (anything uploaded in the app overrides them):

- logo.png             -> logo watermark (MockGrow logo)
- handles/playstore.png, instagram.png, youtube.png, telegram.png, website.png (MockGrow icon)
                       -> default icons for "Additional handles"
- header.pdf (optional) -> page(s) added at the start
- footer.pdf (optional) -> page(s) added at the end

Replace any file here (same name) to change the default permanently.
